New tabs

          
          
          
          
The default view is used for new tabs and for Markdown, text and BBCode files you open; code and config files always open in Edit Only. Font sizes are set under Editor and Preview; Ctrl+mouse wheel zooms one tab, and Ctrl+0 puts it back to 100%.

Translate

          
          
          
Right-click in the editor > Translate. The selected text (or the whole document, when nothing is selected) is sent to Google Translate. This free service needs no key, but it is unofficial: Google may limit how much you translate, or change it without notice. If it stops working, use Google Cloud Translation with your own key.

          

          
Google Cloud API key 

          

          
Right-click in the editor > Translate. The selected text (or the whole document, when nothing is selected) is sent to Google Cloud Translation with your own API key; Google charges per character after the first 500,000 each month. The key is stored encrypted for your Windows account. How to get a key

          

        

        

          
Register file types

          
Tick a type to add notepad.md to its Windows Open with list (just for your Windows account). Your default apps never change: scripts such as .bat, .cmd and .ps1 still run as before.

          

            
            
          

          

          

          
Point Open with and the Explorer menu item at this copy (and tidy up entries left by copies that no longer exist)

        

        

          
Explorer

          
          
On Windows 11 it's under Show more options (or Shift+right-click).

          
Make notepad.md the default app

          
Windows only lets you choose default apps: after ticking a type, pick notepad.md there (or right-click a file > Open with > Choose another app > notepad.md > Always).

        

        

          
Syntax validation

          
          
Full syntax check: JSON (also with comments, JSON5, JSON Lines), YAML, TOML, XML, JavaScript. File format check: Docker Compose (services, ports, volumes, networks), Dockerfile, .env, systemd units, INI, desktop entries. Structure check (brackets, quotes, blocks; not a full syntax check): Python (and indentation), shell scripts, PowerShell, CSS, NGINX, HCL / Terraform, Apache. Other languages: no check.

          
          
          
        

        

          
Showing problems

          
          
          
          
          
F8 / Shift+F8 go to the next / previous problem; the status bar shows how many there are. Files are only read, never run. Languages without a check show “No syntax check” in the status bar.
