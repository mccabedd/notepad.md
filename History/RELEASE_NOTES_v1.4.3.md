## notepad.md v1.4.3

If you have v1.3.0 or later, open **About → About notepad.md → Check for Updates** to install this one. It reopens with all your tabs.

### Changed
- **Line numbers take only the room they need.** The line-number column is now exactly as wide as the biggest line number, so a short file no longer has empty space beside its numbers. It widens by one digit when the file reaches 10, 100, 1,000 lines and so on.

The notes for each version are in the [History folder](https://github.com/mccabedd/notepad.md/tree/main/History).
