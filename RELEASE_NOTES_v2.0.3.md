## notepad.md v2.0.3

If you have v1.3.0 or later, open **About → About notepad.md → Check for Updates** to install this one. It reopens with all your tabs.

### Translate without an API key
Translate now works straight away: by default it uses the **free Google Translate service**, with no key and no cost. **Settings → Translate → Translate with** chooses between:
- **Google Translate (free, no key)**: the new default. It is an unofficial service, so Google may limit how much you translate, or change it without notice.
- **Google Cloud Translation (your API key)**: as in v2.0.2. If you saved a key in v2.0.2, notepad.md keeps using it.

Either way, the text you translate is sent to Google.

### Translate from the spelling menu
Text in another language is underlined as misspelt, and right-clicking an underlined word opens the spelling menu. That menu now has **Translate** too (**Translate to English** and **Choose Language...**), so you can select the text and translate it from there.

The notes for each version are in the [History folder](https://github.com/mccabedd/notepad.md/tree/main/History).
